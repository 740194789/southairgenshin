# SouthAir Genshin · 微信小程序（离线优先 + 多端同步）

原生微信小程序，功能与网页版对齐（原神 / 崩坏：星穹铁道）。断网时可完全离线使用；登录后与网页版共用同一套 Spring Boot API，数据按账号自动合并。

## 一、目录与运行

```
miniprogram/
├── app.js / app.json / app.wxss
├── project.config.json        # 开发者工具项目配置（appid 为 touristappid 占位）
├── components/game-switch/    # 顶部「原神 / 星穹铁道」切换
├── utils/
│   ├── game.js                # 两套游戏的卡池 / 货币 / 文案
│   ├── store.js               # 本地存储（按账号+游戏隔离）、CRUD、统计、同步快照
│   ├── config.js              # 同步服务器地址（部署后替换）
│   ├── api.js                 # 登录 / 注册 / 快照 / 合并请求
│   ├── sync.js                # 节流同步、离线降级、登录失效处理
│   ├── csv.js                 # CSV 读写（带 BOM，可用 Excel 编辑）
│   └── file.js                # 导入导出（聊天文件选择 / 发送文件）
└── pages/
    ├── login/                 # 登录 / 注册 / 离线进入 / 切换账号
    ├── resource/              # 资源页：账号资源、抽数换算、账号与同步状态
    ├── stats/                 # 统计页：保底 / 捕获明光 / 分布 / 备份
    └── wishes/                # 抽卡页：列表、筛选、增删改、十连、批量删除、导入导出
```

用微信开发者工具：**导入项目 → 目录选 `miniprogram` → AppID 选「测试号」或无 AppID 体验**。

## 二、配置同步服务器

1. 部署后端（`/workspace` 的 Spring Boot 服务）到公网服务器，开启 **HTTPS**；
2. 域名需完成 **ICP 备案**，因为微信小程序只允许访问已备案的 HTTPS 域名；
3. 微信公众平台 → 开发 → 开发管理 → 服务器域名 → **request 合法域名** 填入该 HTTPS 域名；
4. 打开 `utils/config.js`，把 `BASE_URL` 换成自己的域名，例如：

```js
var BASE_URL = 'https://api.your-domain.com';
```

`BASE_URL` 仍是 `example.com` 占位域名时，小程序会视为「未配置」，只提供离线模式，不会发起无效请求。

后端接口（均需 `Authorization: Bearer <token>`）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/register` | 注册并返回 token |
| POST | `/api/auth/login` | 登录 |
| GET | `/api/sync/snapshot?game=` | 拉取某游戏的服务端全量快照 |
| POST | `/api/sync/merge?game=` | 上传本地全量数据（含删除墓碑），返回合并后快照 |

## 三、手机上怎么用

1. 在微信开发者工具里点「预览」，用微信扫码即可在手机上打开；
2. 想长期使用：点「上传」，到微信公众平台把版本设为「体验版」，在微信「发现 - 小程序」里打开；
3. 首次进入会到登录页：可登录 / 注册，也可点「离线使用（数据仅存本机）」直接进入；
4. 之后每次启动沿用上次账号；断网时正常记账，联网后自动同步。

## 四、数据存在哪

### 本机（wx storage）

| 内容 | 键 |
| --- | --- |
| 当前游戏 | `sg_game` |
| 登录凭证 | `sg_token`、`sg_user` |
| 离线模式标记 | `sg_offline` |
| 抽卡记录 | `sg_wishes_<userId|anon>_<game>` |
| 账号资源 | `sg_resource_<userId|anon>_<game>` |
| 待同步删除墓碑 | `sg_tomb_<userId|anon>_<game>` |
| 上次同步时间 | `sg_synced_<userId|anon>_<game>` |

- 未登录时用 `anon` 命名空间；登录后按 `userId` 分目录，多个账号互不串数据；
- 卸载小程序、清理微信缓存、换手机都会清空本机缓存，登录后的数据已在云端，重新登录即可拉回。

### 服务端

- 默认 H2 文件库：`data/genshin.mv.db`（`jdbc:h2:file:./data/genshin`）；
- 也可用 MySQL（启动加 `--spring.profiles.active=mysql`），表为 `t_wish_record`、`t_account_resource`、`t_sync_tombstone` 等；
- 网页版与小程序使用**同一个账号**时，看到的是同一份服务端数据。

## 五、离线与多端合并规则

- 每条抽卡记录/资源都带客户端编辑时间 `editedAt`，同步时**按时间取新**（LWW）；
- 删除会写墓碑（`t_sync_tombstone`），旧设备再用旧数据推送也不会把记录「复活」；
- 新记录先查墓碑，再按「名称 + 卡池 + 时间」去重；
- 小程序同步成功后，用服务端返回的全量快照覆盖本地并清空已上传的墓碑；
- 首次登录若检测到旧版离线数据（`sg_wishes_<game>`）或 `anon` 数据，会询问是否并入当前账号。

## 七、导入文件的小技巧

小程序不能直接读电脑磁盘：先把 CSV / JSON 发到微信「文件传输助手」或任意聊天，
在「抽卡」页点「导入记录」，从聊天记录里选择该文件即可。

导入合并按「名称 + 卡池 + 时间」去重；覆盖导入会先清空当前游戏的抽卡记录，并为旧记录写墓碑，避免其他设备把已删除数据带回来。
