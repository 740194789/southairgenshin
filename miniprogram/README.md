# SouthAir Genshin · 离线小程序

微信小程序版，**默认完全离线**：不连接服务器，不需要域名 / HTTPS / 备案。数据只保存在本机小程序缓存里，功能与网页版对齐（原神 / 崩坏：星穹铁道两套游戏）。另提供可选的「链接导入」：通过微信云开发读取米游社抽卡记录链接，或下载公网抽卡记录 JSON / CSV，同样不需要域名与备案。

与网页版（含手机端网页版）**不自动联动**：网页版读服务端账号数据，小程序只读本机缓存。两边通过 JSON / CSV 备份文件互通，格式完全一致。

## 二、手机上怎么用

1. 在微信开发者工具里点「预览」，用微信扫码即可在手机上打开；
2. 想长期使用：点「上传」，到微信公众平台把版本设为「体验版」，在微信「发现 - 小程序」里打开；
3. 个人自用也可以直接把整个目录发给会开发的朋友，用测试号打开。

数据只在本机，换手机 / 清缓存不会同步。

## 四、与网页端互通

### 推荐工作流

1. 电脑网页版在「抽卡」页用「截图识别」把抽卡记录截图转成候选记录（文字 + 头像识别），确认后写入；
2. 网页版「设置」页 → 导出全部数据（JSON）；或在「抽卡」页导出抽卡记录（JSON / CSV）；
3. 通过微信「文件传输助手」把文件发给自己；
4. 小程序「统计」页 → 导入全部数据；抽卡记录也可在「抽卡」页用「链接导入」直接读取。

小程序只负责记录和统计，**不做识图**（小程序端没有 OCR，也不需要后端）。

### 格式一致

- **全量备份**：`{app, version: 5, exportedAt, games: { genshin: {resource, wishes}, starrail: {...} }}`，与网页端「设置 → 导出全部数据」一致，可双向导入。
- **单游戏 JSON 备份**：`{app, version: 4, game, exportedAt, resource, wishes}`，记录字段为
  `uid / wishTime / itemName / rarity / itemType / pool / isUp / pityCount / note / captureTriggered`。
- **录入与导入**：账号资源在「资源」页点「编辑资源」直接修改；抽卡记录在「抽卡」页点「录入五星」手动记录，或用「链接导入」读取米游社抽卡记录 / JSON / CSV 直链。统计页的「资源」分组提供全量备份（两个游戏一次导出 / 导入 JSON）与 UIGF / SRGF 互导，抽卡页不再提供文本导入、文件导入与导出按钮。
- **账号资源**：无单独的导入导出，直接在「资源」页点「编辑资源」改 4 个数值；换设备或与网页端迁移时用「统计」页的全量备份。
- **抽卡记录 CSV**：表头统一为
  `抽卡时间, 物品名称, 星级, 类型, 卡池, 是否UP, 保底计数, 备注, 捕获明光`，带 BOM，Excel / WPS 可直接编辑；保底计数取值范围 1–90。
- **导入规则**：合并模式按「UID + 名称 + 卡池 + 时间」去重；覆盖模式先清空当前游戏记录再写入。
- **UIGF / SRGF 互导**：统计页「资源」分组可导出 / 导入第三方抽卡记录格式——原神为 UIGF v4.2（支持多 UID，按 `hk4e` 分组），星铁为 SRGF v1.0（只支持单 UID，多 UID 时导出第一个 UID）。导入支持 UIGF v4 / v3 与 SRGF v1.0，选择合并或覆盖后先显示导入预演（新增 / 跳过 / 忽略条数）再确认写入；文件本身不含「第几抽 / 是否 UP」时按 UID + 卡池累计推算，导出时附带 `pity / is_up / capture_triggered` 扩展字段供本项目回导恢复。
- **资源**：JSON 备份里的 `resource` 会整体覆盖当前游戏的本机资源。

## 五、链接导入（可选，微信云开发）

小程序不能直接请求任意域名，因此「链接导入」用云函数代下载，不需要域名备案或 HTTPS 配置。

### 首次配置

1. 微信开发者工具顶部点「云开发」，开通并创建一个环境（个人主体可用，按量计费，有免费额度）。
2. 项目已配置 `project.config.json` 的 `cloudfunctionRoot: "cloudfunctions/"`；在文件树中右键 `cloudfunctions/fetchLink`，选择「上传并部署：云端安装依赖」。
3. 编译运行后，抽卡页「链接导入」支持两种链接：
   - 米游社「抽卡记录」链接：与原神 / 星铁游戏对应，自动读取全部卡池、推算保底并判定 UP；链接游戏与当前游戏不一致会提示切换。
   - 抽卡记录 JSON / CSV 的公网直链（`https://…` / `http://…`）或云存储文件 ID（`cloud://…`）。
   两种方式都会在下载后选择合并或覆盖导入。

### 说明

- `app.js` 初始化 `wx.cloud.init({ env: 'qq740194789-d5ghcyv7x748499f9' })`；若更换云环境，请同步修改 env ID。
- 云函数单文件 5MB、单次下载超时 12 秒、最多 3 次跳转。米游社抽卡链接按卡池分页读取，云函数会根据自身超时自适应页数（3 秒约 2–4 页，20 秒最多 30 页）；客户端用 `end_id` 自动续页，一条链接里的全部历史会自动读完，不需要拆分链接。
- 星铁「联动」池已映射 `gacha_type=21/22`，米游社链接导入会包含联动记录；联动角色与光锥在应用内仍归入同一个「联动」池。
- 联动池不参与星缘相邀判定，UP 标记统一为否（与网页端一致）。
- 文件链接按抽卡记录格式解析（记录数组、单游戏备份或全量备份中的当前游戏记录）。
- 未开通云开发或未部署 `fetchLink` 时，链接导入会提示失败，不影响原有离线功能。

> 手机端网页版和小程序是两条独立的数据线：网页版登录后看到的是服务端账号数据，小程序只看本机缓存，两者不会自动合并。

## 七、手机端怎么录入 / 导入

- **账号资源**：在「资源」页点「编辑资源」，弹窗里直接改 4 个数值并保存；没有单独的导入导出，跨设备迁移用「统计」页的全量备份。
- **抽卡记录**：在「抽卡」页点「录入五星」手动记录；也可以点「链接导入」读取米游社抽卡记录链接，或抽卡记录 JSON / CSV 直链。
- **接收电脑端文件**：电脑网页端「设置 → 导出全部数据」的 JSON 先发到微信「文件传输助手」，再在小程序「统计」页点「导入全部数据」从聊天记录选择。
- **换设备 / 备份**：用「统计」页的「导出全部数据 / 导入全部数据」，一个 JSON 包含两个游戏的全部资源与抽卡记录，电脑端和手机端可互换。
- 导入合并按「UID + 名称 + 卡池 + 时间」去重；覆盖导入会先清空对应游戏的抽卡记录。

小程序不能直接读电脑磁盘，所以文件必须经过微信聊天记录中转；能手动填写的内容已优先改为小程序内直接录入。
