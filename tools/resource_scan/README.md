# 资源截图识别（半自动 · 方案 B）

独立于 exe 的小脚本：只截屏识别，**不读游戏内存、不模拟键鼠、不修改游戏数据**。
识别结果打印到控制台并复制到剪贴板，可选回填本地服务。

## 识别项

原石、摩拉、纠缠之缘、相遇之缘、创世结晶、大英雄的经验、冒险家的经验、流浪者的经验。

## 环境

1. 安装 Python 3.9+（勾选 Add to PATH）。
2. 安装 Tesseract OCR（Windows 推荐 UB Mannheim 版），并加入 PATH。
3. 双击 `run.bat`，首次运行会自动创建 `.venv` 并安装依赖。

## 按页面分别校准

游戏里没有一个页面同时显示全部资源，所以每个页面单独保存一套区域：

| 示例页面 | 常见可识别项 |
| --- | --- |
| 背包-贵重道具 | 摩拉、纠缠之缘、相遇之缘（顶部可能还有原石） |
| 背包-养成道具 | 大英雄的经验、冒险家的经验、流浪者的经验 |
| 商店 / 充值页 | 创世结晶、原石 |

校准流程：

```text
run.bat --calibrate
```

1. 控制台会列出现有页面，输入编号重新校准，或输入 `0` 新建页面（如「背包-贵重道具」）。
2. 打开游戏对应页面，按提示左键框选该页显示的资源数字区域，并输入真实数值。
3. **本页没有的资源直接右键跳过**；再次校准旧页面时，跳过的项会保留原有区域。
4. 全部处理完后自动保存到 `config.json`，并用本次录入的真实值补充数字模板。

区域按截图相对坐标保存（0–1），换分辨率后通常仍可用；偏差较大时重新校准该页面。

## 日常识别

```text
run.bat                    # 选择页面后识别，结果写剪贴板
run.bat --page 背包         # 直接使用名称/id 包含「背包」的页面
run.bat --list-pages       # 查看已校准页面
run.bat --once             # 识别一次后退出
run.bat --dry-run          # 只打印，不写剪贴板
```

识别时只处理当前选中页面的已校准区域，不会自动翻页；交互模式下输入 `p` 切换页面，`c` 重新校准当前页面。

首次使用（还没有任何已校准区域）直接运行 `run.bat` 时，会自动进入校准流程，而不是先报错。

## 在 exe 内启动

电脑端资源页的「录入资源」菜单里新增了「电脑识图工具」：

- 首次点击：检测到还没有校准区域，自动打开校准窗口。
- 之后点击：直接打开识图工具。
- 后端只负责启动 `tools/resource_scan/run.bat`，不传任意命令；脚本可放在程序目录下的 `tools/resource_scan`，或通过 `app.resource-scan.dir` 指定位置。

## 双引擎与置信度

- 引擎 1：Tesseract OCR（`eng` + 数字白名单，`--psm 7`）。
- 引擎 2：二值化 + 连通域切数字 + 与校准生成的数字模板做归一化匹配。
- 两引擎结果一致 → `一致`；不一致 → `需确认`（最终值取 OCR，并同时显示模板值）；
  仅一个引擎有结果 → `仅 OCR` / `仅模板`；都没有 → `缺失`。

未校准的字段显示「未校准」，不会参与回填。

## 可选回填

```text
run.bat --push --token <登录token> --url http://localhost:8080
```

回填调用现有 `PUT /api/resources`，只提交识别成功的字段，未识别项保持原值。

## 文件说明

- `scan.py`：页面选择、截屏、双引擎识别、剪贴板与回填
- `calibrate.py`：按页面校准与模板生成
- `config.json`：窗口标题、页面列表（每页一套区域）、上次使用的页面
- `templates/`：数字模板（校准后按页面生成，`templates/<页面id>/0-9.png`，缺失数字回退到全局模板）
- `run.bat`：创建虚拟环境、安装依赖、启动
