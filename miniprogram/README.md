# SouthAir Genshin · 离线小程序

微信小程序版，**完全离线**：不连接服务器，不需要域名 / HTTPS / 备案。数据只保存在本机小程序缓存里，功能与网页版对齐（原神 / 崩坏：星穹铁道两套游戏）。

与网页版（含手机端网页版）**不自动联动**：网页版读服务端账号数据，小程序只读本机缓存。两边通过 JSON / CSV 备份文件互通，格式完全一致。

## 一、目录与运行

```
miniprogram/
├── app.js / app.json / app.wxss
├── project.config.json        # 开发者工具项目配置（appid 已填 wx5b8aba02be73f4b6）
├── components/game-switch/    # 顶部「原神 / 星穹铁道」切换
├── utils/
│   ├── game.js                # 两套游戏的卡池 / 货币 / 文案
│   ├── store.js               # 本地存储、抽卡 CRUD、统计与保底计算
│   ├── csv.js                 # CSV 读写（带 BOM，可用 Excel 编辑）
│   └── file.js                # 导入导出（聊天文件选择 / 发送文件）
└── pages/
    ├── resource/              # 资源页：账号资源 + 抽数换算
    ├── stats/                 # 统计页：保底 / 捕获明光 / 分布 / 备份
    └── wishes/                # 抽卡页：列表、筛选、五星录入、批量删除、导入导出
```

用微信开发者工具：**导入项目 → 目录选 `miniprogram` → AppID 会自动读取 `wx5b8aba02be73f4b6`**（换账号时在工具「详情 → 基本信息」里改）。

## 二、手机上怎么用

1. 在微信开发者工具里点「预览」，用微信扫码即可在手机上打开；
2. 想长期使用：点「上传」，到微信公众平台把版本设为「体验版」，在微信「发现 - 小程序」里打开；
3. 个人自用也可以直接把整个目录发给会开发的朋友，用测试号打开。

数据只在本机，换手机 / 清缓存不会同步。

## 三、数据存在哪

| 内容 | 存储位置 |
| --- | --- |
| 当前选择的游戏 | `wx storage: sg_game` |
| 原神抽卡记录 | `wx storage: sg_wishes_genshin` |
| 星铁抽卡记录 | `wx storage: sg_wishes_starrail` |
| 原神资源 | `wx storage: sg_resource_genshin` |
| 星铁资源 | `wx storage: sg_resource_starrail` |
| 记录自增 ID | `wx storage: sg_seq_<game>` |

- 卸载小程序、清理微信缓存、换手机都会丢数据；
- 建议定期在「统计」页点「导出全部数据」（全量备份），文件会通过微信发送，可存到「文件传输助手」再转存电脑。

## 四、与网页端互通

### 推荐工作流

1. 电脑网页版用「截图识别」把截图转成抽卡记录 / 资源数字，确认后写入；
2. 网页版「统计」页 → 导出账号资源；「抽卡」页 → 导出抽卡记录（JSON / CSV）；
3. 通过微信「文件传输助手」把文件发给自己；
4. 小程序「统计」页 → 导入资源；「抽卡」页 → 导入记录，选择对应文件。

小程序只负责记录和统计，**不做识图**（小程序端没有 OCR，也不需要后端）。

### 格式一致

- **全量备份**：`{app, version: 5, exportedAt, games: { genshin: {resource, wishes}, starrail: {...} }}`，与网页端「设置 → 导出全部数据」一致，可双向导入。
- **单游戏 JSON 备份**：`{app, version: 4, game, exportedAt, resource, wishes}`，记录字段为
  `wishTime / itemName / rarity / itemType / pool / isUp / pityCount / note / captureTriggered`。
- **导入模板**：抽卡记录 CSV 为表头 + 一条三星示例行、JSON 为一条三星示例；账号资源 CSV 只有表头、JSON 字段为 null。示例数据导入时会被忽略或拒绝，不会污染真实数据。
- **账号资源 CSV**：表头为 `原石/星琼, 摩拉/信用点, 纠缠之缘/星轨专票, 相遇之缘/星轨通票`，导入只覆盖填写了数值的字段。
- **抽卡记录 CSV**：表头统一为
  `抽卡时间, 物品名称, 星级, 类型, 卡池, 是否UP, 保底计数, 备注, 捕获明光`，带 BOM，Excel / WPS 可直接编辑；保底计数取值范围 1–90。
- **导入规则**：合并模式按「名称 + 卡池 + 时间」去重；覆盖模式先清空当前游戏记录再写入。
- **资源**：JSON 备份里的 `resource` 会整体覆盖当前游戏的本机资源。

> 手机端网页版和小程序是两条独立的数据线：网页版登录后看到的是服务端账号数据，小程序只看本机缓存，两者不会自动合并。

## 六、导入文件的小技巧

小程序不能直接读电脑磁盘：先把 CSV / JSON 发到微信「文件传输助手」或任意聊天，
在「抽卡」页点「导入记录」，从聊天记录里选择该文件即可；导入前会先让你选择「下载 CSV 模板 / 下载 JSON 模板 / 直接导入」。

导入合并按「名称 + 卡池 + 时间」去重；覆盖导入会先清空当前游戏的抽卡记录。
